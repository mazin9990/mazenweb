موقع شخصي متكامل يستعرض السيرة الذاتية، معرض الأعمال، والمدونة للحديث عن الخدمات البرمجية والإبداعية، بالإضافة إلى **منصة السير الذاتية الذكية المتوافقة مع أنظمة ATS المدعومة بأدوات تفاعلية وذكاء اصطناعي**.

---

## 🚀 الميزات الرئيسية

- 🎭 **تكييف واجهة المستخدم والتصميم:**
  - دعم كامل للوضع الداكن (Dark Mode) والوضع الفاتح (Light Mode).
  - دعم ثنائي اللغة (العربية والإنجليزية - RTL/LTR).
  - تصميم متجاوب 100% مع كافة الشاشات والأجهزة الذكية.

- 📄 **منصة السير الذاتية الذكية (ATS Resume Builder):**
  - بناء وتوليد سير ذاتية متوافقة مع خوارزميات الفرز الآلي (ATS).
  - **11 أداة ذكاء اصطناعي تفاعلية:**
    - توليد سيرة ذاتية واقعية مخصصة حسب المسمى الوظيفي.
    - إنشاء خطاب تغطية احترافي (Cover Letter).
    - مطابقة السيرة الذاتية مع الإعلانات والوصف الوظيفي.
    - تحسين الخبرات وصياغتها بأفعال قوية معززة بالأرقام والنسب.
    - تقييم وفحص جودة السيرة الذاتية (Resume Score & Audit).
    - ترجمة كاملة للسيرة الذاتية.
  - دعم تصاميم متعددة (كلاسيكي، عصري، أكاديمي، مخصص للمطورين).
  - **تصدير المخرجات مباشرة بصيغة PDF مقاس A4.**

- 💼 **معرض الأعمال والخدمات:**
  - تصفح المشاريع مع تصفية تفاعلية حسب التصنيف (تصميم ويب، تطوير ويب، تطبيقات).
  - استعراض الخبرات والشهادات التعليمية والدورات التدريبية.

---

## 🛠️ التقنيات المستخدمة

- **HTML5 & CSS3:** بناء الهيكل الأساسي واستخدام متغيرات CSS للثيمات.
- **Tailwind CSS:** لتنسيق الواجهات السريعة وواجهة منصة ATS.
- **React.js (UMD) & Babel:** لإدارة حالة البيانات التفاعلية لبناء السير الذاتية.
- **FontAwesome & Google Fonts:** للأيقونات والخطوط العربية والإنجليزية (Cairo, Tajawal, Poppins).
- **html2pdf.js:** لتحويل واستخراج صفحات السيرة الذاتية إلى ملفات PDF عالية الجودة.
